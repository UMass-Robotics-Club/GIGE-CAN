# Baics
- Represents link and physical layer in OSI model
- Data carried over 4 differential twisted copper pairs
- Standard cable structure is unshielded Twisted Pair (UTP)
    - Categorized according to the maximum carrier freq (Cat1-Cat8)
        - Gigibit requires Cat5 or higher
    - Has 100 ohm impedance to reduce signal reflection
